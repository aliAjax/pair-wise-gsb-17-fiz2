# hxwl-03 钻孔取样与试验跟踪台

钻孔编录的取样与试验跟踪面板：每个孔按回次登记样号、起止深度、样型、取土器编号和封样时刻，送检、接收、入库、退回全程留痕。

## 技术栈

React + Vite + TypeScript + CSS（无额外依赖，数据保存在浏览器 localStorage）

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5103

## 功能

- **登记**：按孔、按回次录入样号、起止深度、样型、取土器编号、取样与封样时刻
- **自动复核**：深度与已编录分层对不上（给出深度差）、同孔样号重复、封样超过两小时的记录先留在「待复核」
- **送检与接收**：合格记录进入「已送检」；实验室核对样号与实收重量，少样可退回，合格结果写入后冻结原记录为「已入库」
- **现场更正**：不改写原版本，另建一条带原因的版本并重新复核，历史版本可展开查看
- **检索**：按孔号、样号、深度差、更正/退回原因等关键词过滤，状态与孔位可筛选
- **分层结构**：资料（types/seed）、判定（rules）、保存（storage）、界面（components/App）分开，localStorage 持久化，刷新后待复核/已送检/已入库状态不丢
